# AI Tech Radar Daily

## 今日重点

- **Agent Harness 设计对性能影响显著**：一项预注册消融实验显示，在相同模型和任务下，仅改变 Agent harness 设计（如规则放置、证据顺序、轮次结构）即可导致 60% 至 82% 的准确率波动（22 个百分点）。关键因素包括：显式规则提升 13%，任务前置提升 6.5%，额外推理轮次降低 5%，清空上下文仅保留摘要降低 12%，跨阶段新会话交接降低 15%。
- **DeepSeek-V4-Flash 性能超越 Pro**：DeepSeek-V4-Flash-0731 在基准测试中大幅超越 V4-Pro-Preview，且通过 unsloth 量化 GGUF 格式在单张 40GB A100 上高效运行（162GB 模型仅用 15.8GB VRAM，生成速度 16.1-17.7 tok/s），支持 Codex 驱动的完整 agentic 编码循环。
- **DeepSeek 快速迭代**：V4-Flash 更新，V4-Pro 即将正式发布，开源模型竞争加剧。

## 技术趋势

- **Agent Harness 工程化成为关键**：实验证明，Agent 系统的性能不仅取决于模型能力，更受 harness 设计（提示结构、上下文管理、轮次设计）影响，推动行业关注标准化评估和工程实践。
- **MoE 模型本地部署门槛降低**：量化 + CPU 卸载方案使大模型在单卡 GPU 上高效运行，加速本地 Agent 工作流普及。
- **轻量级模型竞争力上升**：Flash 版本性能超越 Pro，可能改变模型选择格局，高性价比模型受青睐。

## 开发者建议

- **系统化测试 Agent Harness**：参考开源评估框架，在自身项目中测试提示结构、上下文管理及轮次设计，采用预注册实验确保结果可靠。
- **关注 DeepSeek-V4-Flash 部署**：评估其量化版本在本地 GPU 上的性能，尝试用于编码和 Agent 场景，降低推理成本。
- **跟踪 V4-Pro 发布**：关注官方技术报告和基准数据，评估其性能与开源策略，适时调整模型选型。
