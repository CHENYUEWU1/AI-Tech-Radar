# 科技信息差分工说明

生效日期：2026-08-01

## 总原则

AI Tech Radar 负责 AI 模型本身的技术信息，Codex 负责其余所有科技信息。两份内容互补，不重复。

## AI Tech Radar 负责

- 模型发布与版本更新（DeepSeek、GPT、Claude、Kimi、MiniMax 等）
- 基准测试、跑分、能力对比
- 开源权重 vs 闭源 API
- 推理引擎、本地部署、模型压缩、内存优化
- 模型定价和 API 成本
- AI 在数学、科学等基础研究上的技术突破

## Codex 负责

- 芯片、存储、内存供给和算力基建
- AI 安全事件、智能体失控、责任归属
- 政策和监管（国内、欧盟、美国等）
- 公司动态、财报、融资、资本市场和泡沫风险
- 消费电子、汽车、机器人、具身智能
- 产品商业化、内容平台、开发者生态
- 交叉事件中偏产业、市场、风险的部分

## 交叉事件处理

一条新闻同时涉及两边时，按内容拆分：

- 模型细节、跑分、技术方案归 AI Tech Radar
- 硬件门槛、商业影响、产业链反应、市场信号归 Codex

## 输出约定

- 用户说"今天的科技信息差"时，Codex 默认只补充 Radar 之外的部分
- 每条信息尽量附来源链接，标注时间和渠道
- 如果某条消息属于 Radar 范围但 Radar 尚未覆盖，Codex 可简要提示"属于模型侧，建议交给 Radar 深挖"
